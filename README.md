# Polarbad Sandnes – homepage redesign prototype

Static prototype by Kilowott, published with GitHub Pages.

- `index.html` – Norwegian homepage (main page)
- `en.html` – English version
- `images/` – optimised photos
- `support.js` – runtime for the interactive parts (tub finder, series panels, booking request, FAQ)
- `src/` – design sources; `tools/` – Norwegian translation and build scripts

Fonts load from Google Fonts. All photos are from polarbad.no.
